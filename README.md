《江城子·念》

长街春涨日熔金，珠玑陈，笑言频。
橡皮无迹，斜照烙空痕。
暖色漫铺如旧岁，镀尘影，灼孤身。

蓦然声渺影空沉，橱窗明，照谁人？
人潮涌处，步履滞深春。
万盏灯浮千叠界，风卷絮，碎云纹。
